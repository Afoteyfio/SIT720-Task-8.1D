# SIT720-Task-8.1D
Sydney Housing Price Prediction and Decision Support System

## Project Files

- `s225674015_task_8_1D.ipynb` - Jupyter notebook containing the data analysis, model development and evaluation.
- `app.py` - Streamlit application for predicting property sale prices.
- `random_forest_model.pkl` - Saved Random Forest model used by the application.
- `data/s225674015_task_8.1D.xlsx` - Sydney housing dataset used in the project.
